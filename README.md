# 🏠 House Price Predictor using Linear Regression

This project demonstrates a simple Machine Learning model using **Linear Regression** to predict house prices based on square footage, number of bedrooms, and bathrooms.

---

## 📌 Objective

Predict the **Sale Price** of houses using key features such as:
- `GrLivArea` (Above ground living area)
- `BedroomAbvGr` (Number of bedrooms)
- `FullBath` (Number of full bathrooms)

---

## 🧠 Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn (LinearRegression, train_test_split, evaluation metrics)

---

## 📁 Dataset

- File: `data_description.txt`  
- Must include columns: `GrLivArea`, `BedroomAbvGr`, `FullBath`, and `SalePrice`

> Replace `data_description.txt` with a proper CSV or use an actual dataset like the Ames Housing dataset from Kaggle for more features.
